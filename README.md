# ربات بله طیبستان (Taiyebestan Bale Bot)

ربات پیام‌رسان بله برای فروشگاه [taiyebestan.ir](https://taiyebestan.ir)

## امکانات
- خوشامدگویی به کاربران جدید
- جستجوی محصولات با نام کامل یا بخشی از نام و ارسال لینک
- مینی‌اپ برای نمایش کامل سایت

## ساختار پروژه
```
taiyebestan/
├── bot/
│   ├── main.py          # نقطه ورود ربات (webhook یا polling)
│   ├── handlers.py      # هندلرهای پیام
│   ├── products.py      # جستجو و کش محصولات
│   └── config.py        # تنظیمات
├── requirements.txt
├── passenger_wsgi.py    # برای استقرار روی cPanel
└── README.md
```

## روش پیشنهادی: وب‌اپ پایتون روی cPanel (بهتر از افزونه وردپرس)

### چرا پایتون بهتر است؟
- منطق جستجوی fuzzy و کش محصولات انعطاف‌پذیرتر است
- وابستگی کمتر به وردپرس (اگر سایت تغییر کند ربات مستقل می‌ماند)
- مینی‌اپ و webhook راحت‌تر پیاده‌سازی می‌شوند
- کتابخانه‌های آماده مثل `python-bale-bot` یا `pyrobale` وجود دارد

افزونه وردپرس فقط در صورتی خوب است که بخواهید مستقیماً از WooCommerce REST API داخل وردپرس استفاده کنید و همه چیز داخل همان سایت باشد. برای ربات مستقل، پایتون روی cPanel یا VPS توصیه می‌شود.

## مراحل ساخت از صفر

### ۱. ساخت ربات در بله
1. در بله به `@BotFather` پیام دهید
2. دستور `/newbot` را بفرستید
3. نام نمایشی و یوزرنیم (باید به bot ختم شود) را وارد کنید
4. توکن را ذخیره کنید

### ۲. آماده‌سازی محصولات
سایت وردپرس/ووکامرس است. دو راه دارید:
- **ساده**: لیست محصولات را به صورت JSON یا CSV دستی/اسکریپت استخراج کنید
- **بهتر**: از WooCommerce REST API استفاده کنید (Consumer Key/Secret بسازید)

### ۳. استقرار روی cPanel با Python
1. در cPanel بخش **Setup Python App** (یا Application Manager) یک اپلیکیشن بسازید
2. نسخه پایتون ۳.۹+ انتخاب کنید
3. مسیر اپلیکیشن را مشخص کنید (مثلاً `taiyebestan_bot`)
4. virtualenv ساخته می‌شود
5. فایل‌های پروژه را آپلود کنید
6. `pip install -r requirements.txt` را در ترمینال virtualenv اجرا کنید
7. `passenger_wsgi.py` را تنظیم کنید
8. Webhook را به آدرس `https://yourdomain.com/bot` ست کنید

### ۴. مینی‌اپ
در دکمه اینلاین یا منوی ربات، دکمه WebApp با آدرس سایت یا صفحه اختصاصی مینی‌اپ قرار دهید.

مستندات مینی‌اپ: https://docs.bale.ai/miniapp
